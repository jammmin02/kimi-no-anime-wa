# lib/

サーバー・クライアントの両方から使える、フレームワークに依存しない
汎用ロジックを置くディレクトリです。

- `utils/` : 日付整形、文字列処理などの汎用ユーティリティ関数。
- `constants/` : アプリ全体で共有する定数(ページネーション件数、
  最小レビュー数のしきい値など)。
- `types/` : 複数箇所で共有する TypeScript の型定義。
- `i18n/` : 画面に表示する文字列を一元管理するプレーンオブジェクト(現状は `ja.ts` のみ)。
  本格的な i18n 対応は P1-7 で行う予定なので、それまでは画面側で文字列を直接
  ハードコードせず、必ずここ経由で参照すること。

外部 API(AniList・Claude・LibreTranslate)への実際の通信ロジックや、
DB アクセスなど「サーバーでのみ実行してよい処理」は `server/` 側に置き、
ここには置かないこと。
