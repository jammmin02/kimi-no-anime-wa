# components/

画面を構成する React コンポーネントを置くディレクトリです。

- `ui/` : ボタン・カード・入力欄・モーダル・バッジ・評価(星)・スケルトン・空状態など、
  デザインシステム(P0-5)に基づく汎用 UI コンポーネント。色・spacing・角丸・シャドウは
  必ず `app/theme.css` で定義したトークン(= Tailwind のユーティリティクラス。
  `bg-primary` / `text-muted-foreground` / `rounded-lg` など)だけを参照し、
  `#RRGGBB` の直書きやページ固有の余白の値をハードコーディングしない。
- `layout/` : ヘッダー(ナビゲーションバー)、フッターなど、ページ全体のレイアウトを
  構成するコンポーネント。

ページ固有にしか使わないコンポーネントは、原則として該当する `app/**` の
ルートセグメント内に置き、複数の画面で再利用するものだけをこのディレクトリに
昇格させてください。

## デザインシステムのルール(P0-5 以降、必ず守ること)

- **新しい色・ボタンスタイルをページごとに作らない。** ボタンは `ui/Button.tsx` の
  variant(primary/secondary/outline/ghost/destructive)、バッジは `ui/Badge.tsx` の
  variant から選ぶ。今の variant で足りない場合は、ページ側で応急処置をせず、
  この README とセットになっている `app/theme.css` のトークン自体を拡張すること。
- **アイコンは `lucide-react` のみを使う。** 他のアイコンライブラリ(react-icons,
  heroicons, @radix-ui/react-icons 等)を混在させないこと。
- **スタイルガイド(`app/style-guide`)を新しいコンポーネントの確認場所として使う。**
  コンポーネントを追加/変更したら、このページにも使用例を追加し、既存のトークンを
  再利用できているか目視確認する。
- ダーク/ライトモードは「ライト優先 + ダークは選択式」。`dark:` バリアントは
  `.dark` クラスベース(OS 設定には自動追従しない)。詳細は `app/theme.css` の
  コメントと `ui/ThemeToggle.tsx` を参照。
